# Presentations

Seth Green's talks, one folder per talk. Most are R Markdown beamer decks built with the
[HSFL slide template](https://github.com/setgree/HSFL-slides).

- `AI-tournament-slides/`: precedents from other modeling competitions for rules and cheating prevention, April 2026
- `AVA26/`: AVA Summit, Toronto, May 2026: "In favor of weird, exploratory vegan research"
- `NEST March 2026/`: Network for Sustainable Food Transitions (NEST) workshop, March 2026
- `RECAP-December-2025/`: "Building empathy for chickens," December 2025
- Reducetarian Summit, October 2025: source is the sample deck in [HSFL-slides](https://github.com/setgree/HSFL-slides/tree/main/sample_presentation)
- `Reducetarian Summit 2026/`: Reducetarian Summit, October 2026, Raleigh, NC

The four talks that used to be separate repos (ava26, NEST-presentation-march-2026,
recap-dec-2025-slides, reducetarian-2026) were merged here with their history.
